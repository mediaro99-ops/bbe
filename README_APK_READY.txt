ProfitRide 2.0 — APK READY

Noutăți:
- afișaj flotant compact, mereu peste Bolt când aplicația de șofer este în prim-plan;
- cardul poate fi mutat liber sus/jos/stânga/dreapta cu degetul;
- nu există buton Acceptă/Refuză în ProfitRide și aplicația nu apasă nimic în locul șoferului;
- la Refuză: reset automat la 0 / așteaptă ofertă;
- la Acceptă: pauză automată;
- în Waze: afișajul ProfitRide se ascunde complet;
- când revii în Bolt: afișajul reapare în starea curentă;
- voce: anunță doar suma ofertei o singură dată;
- calcule NET/km, NET/oră, profit, cost real per km și SCORE;
- costuri fixe lunare, combustibil/energie, consum, mentenanță, program, km/săptămână, țintă lunară și praguri;
- logo nou ProfitRide;
- credit discret: Creat de Plesia Razvan.

Build online Codemagic:
1. Încarcă TOT conținutul acestei arhive în rădăcina repo-ului GitHub.
2. Verifică să existe app/build.gradle, settings.gradle și codemagic.yaml.
3. În Codemagic: Check for configuration files -> Start new build.
4. La final descarci ProfitRide.apk din Artifacts.

Dacă actualizezi repo-ul vechi:
- înlocuiește folderul app complet;
- înlocuiește build.gradle, settings.gradle, gradle.properties și codemagic.yaml;
- poți păstra restul fișierelor personale din repo.
